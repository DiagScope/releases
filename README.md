# DiagScope Releases

Public release assets for [DiagScope](https://github.com/DiagScope/diagscope) — a static analyzer for Java/Kotlin projects.

## Install via Homebrew

```bash
brew tap DiagScope/tap
brew install diagscope
```

## Manual Download

Download the latest JAR from the [Releases](https://github.com/DiagScope/releases/releases) page.
Requires **Java 25+**.

```bash
java -jar diagscope-<version>.jar scan --help
```
